# OpenSynth 出厂预设

OpenSynth 自带四个原始音色补丁（`Init`、`Neon Bass`、`Glass Pad`、`Pulse Pluck`），以及下面列出的 62 个分类预设，所以预设浏览器中共有 66 个音色补丁。每个预设都是在 `Init` 之上的一组覆盖值：加载时从初始音色出发，只改动表中列出的控制。

## 加载预设

1. 在音色补丁编辑器的标题栏中，点击显示音色补丁名称的字段，打开**预设浏览器**。
2. 用方向键或鼠标高亮一个预设。在**搜索预设**中输入文字，可按名称、类别或标签筛选。
3. 按 **Enter**，或双击该行。

加载会在一个可撤销的步骤中替换整个音色补丁：参数、效果链以及 `patch:` 来源标签。预设没有声明的键都会被重置。字段旁边的**加载**按钮用来导入外部预设文件，并不从浏览器加载。

浏览器按类别列出出厂预设库，下方是**用户库**一节。加了星标的预设会移到顶部的**收藏**一节。每一节都有相同的搜索、`▶` 试听和加载操作。

“演奏示例”一列写的是每个预设设计时所针对的乐句。它只是一个起点，并不限制你怎么演奏。浏览器自带的 `▶` 试听总是播放同一个六音乐句，所以试听比较的是音色，而不是乐句。

## 各类别说明

- Bass（10 个）：单音、居中，滤波器和振幅的释放都很短，让低频在底鼓下保持紧凑。这一类包括一个超低音锚点、一个振荡器独立齐奏的宽贝斯、一个折叠低吼，以及两个拨弦贝斯。
- Lead（10 个）：明亮的单线音色，大多是带滑音的单音模式。其中三个各展示引擎的一个方面：包络驱动波表位置、两个并联带通构成元音，以及带驱动的梯形滤波器。
- Pad（12 个）：八声部复音，起音慢、齐奏失谐宽、释放长。这一类用到了波表扫动、SVF 共振峰、低频厚重的梯形滤波铺底，以及三种不同的效果架。
- Pluck（9 个）：起音尖锐、衰减短，适合 riff、hook 和琶音，包括一个环形调制的钟声、一个 PWM 拨弦，以及一个经过延迟和混响的拨弦。
- Keys（8 个）：带衰减音体的复音和弦音色，从干净的音叉和钟声，到饱和的音叉、带通 clav 和移相器键盘。
- Brass（6 个）：中频突出的渐强和短奏，从三振荡器的号角线条到有混响衬托的电影感渐强。
- Fx（7 个）：用于效果和过渡的运动纹理：上升音效、持续音、一个混沌场、一个步进音序器门，以及一条由三个模块组成的氛围效果链。

## 电平与音色范围

每次改动后都会以无界面方式测量整个预设库，所以变轻、损坏或过响的预设都会让检查失败。每个预设在自己的音区（贝斯低两个八度）渲染试听乐句（140 BPM 下的六个八分音符），外加一秒的释放尾音。渲染结果必须满足以下范围：

- 峰值：音色补丁输出处最高 −1 dBFS，且没有任何采样点达到满刻度。
- 电平：RMS 在该类别的范围内。整个库的 RMS 跨度不超过 10 dB。
- 峰值因数和频谱质心：在该类别的范围内，所以塌掉的音色（全是延音、没有起音）或变成噪声的音色会失败。
- 直流偏移：低于满刻度的 0.5 %，且没有 NaN 或 Inf 采样。
- 静音：每个预设的峰值都必须高于 −24 dBFS。

### 试听响度

浏览器试听会把每个候选音色匹配到 −17.2 LUFS 的库参考响度，所以上表比较的是音色而不是电平。这个参考值是 62 个音色补丁综合响度的中位数，用同一个六音试听乐句、以渲染器的 BS.1770-4 响度表测得。匹配前这些音色补丁的跨度为 14.9 LU，匹配后小于 0.4 LU。

实时预览不做这种匹配，而是按乐器本身产生的电平播放音色补丁。声音路径上每一个可能抬高电平的环节都带有归一化，所以不需要浏览器先渲染并测量乐句，整个库也能保持在 −6 dBFS 以下。最响的音色补丁峰值为 −6.21 dBFS；参见 [Synth output levels](../synth-levels.html)（英文）。

### 运行检查

`scripts/check-factory-presets.py` 实现了上述测量和范围检查。改动预设库后，用当前构建的 `ocp` 可执行文件运行它：

```sh
python3 scripts/check-factory-presets.py --ocp target/debug/ocp
```

前端测试负责检查数据本身：名称唯一、各类别的数量、参数键能被出厂预设表接受、包络完整，以及没有占位文字。

## 脉宽与直流

引擎的两个特性影响了这个库的音色设计。把 `osc.<x>.pulse_width` 设为偏离 `0.5` 的值会产生直流分量，默认波表库中的窄脉冲帧（位置高于 `0.5`）也会，因为读取时保留了帧的均值。因此这个库的窄脉冲取自不含直流的 PWM 变形，波表位置都停在 `0.5` 或以下。
