# 速度、拍号与摇摆

工程时钟把写出的位置换算成秒。它读取三类声明：工程头部的 `tempo:` 和 `time_signature:`，`tempo_map:` 和 `time_sig_map:` 中的变化点，以及 `swing:`。这些都写在工程文件里。解释器读取它们，但从不改写音符。

## 基础值

```ocp
@project "Clock"
  tempo: 120
  time_signature: 4/4
```

`tempo` 的单位是每分钟四分音符数。`time_signature` 设定第 1 小节的拍号，并一直沿用到某个变化点设定新的拍号为止。

## 变化点

```ocp
@project "Clock"
  tempo: 120
  time_signature: 4/4
  tempo_map:
    9:1 = 90 bpm
    17:1 = 132 bpm
  time_sig_map:
    25:1 = 3/4
```

`tempo_map` 中的一个点写作 `bar:beat = bpm`，后缀 `bpm` 可以省略。`time_sig_map` 中的一个点写作 `bar:beat = numerator/denominator`。每个点单独占一行，缩进比所属的键更深；点与点之间不用逗号分隔。两种映射都使用绝对位置。请按时间线顺序列出各点，同一位置不能出现两次。位于 `1:1` 的点会取代头部的值。

加载器会检查以下规则：

- 拍号变化必须位于小节开头（第 1 拍，细分 0）。
- 速度变化是阶跃式的：速度一直保持到下一个点。没有渐变；逐渐变化请写成一串变化点。
- 位置含糊或顺序错乱的映射在解析文件时就会被拒绝。加载器既不修复，也不重新排序。
- 速度变化落在网格位置之间时，对应的 `tempo_map` 点可以在其细分内带一个剩余偏移（JSON 导出中的 `offset_quarters`）。

拍号变化只影响小节计算。一拍是拍号分母对应的音符（4/4 中是四分音符，6/8 中是八分音符），一个细分是这一拍的四分之一。音符时值和 `start_beat` 始终以四分音符为单位，所以在任何拍号下，二分音符都等于两个四分音符。

## 映射影响的方面

- 渲染通过映射把位置换算成秒，所以一次速度变化会让其后的所有内容变短或变长。
- 编排中的段落跨度以小节位置表示。因此拍号变化会改变段落所占的小节数和渲染长度。
- MIDI 导出把 `tempo_map` 写成速度事件，把 `time_sig_map` 写成拍号事件，导出的文件保留映射后的时钟。
- 请求音乐时间的托管插件收到的是映射后的位置。带速度映射的工程通过 AU 路径播放。VST3 路径从走带获取位置，不会重新读取文件。

## 摇摆

`swing: 55%` 会推迟所选网格上反拍的音符，网格默认为八分音符。百分比表示反拍在一对网格步中所处的位置，以这一对的长度为 100%：

```text
delay_quarters = (percentage / 100 - 0.5) * grid_scale
```

在八分音符网格上 `grid_scale` 为 1，在十六分音符网格上为 0.5。下表对应默认的八分音符网格：

| `swing:` | 延迟（四分音符） | 听感 |
|----------|-----------------------|------|
| 50 % | 0 | 平直（未写值时的默认值） |
| 55 % | +0.05 | 轻微后推，120 BPM 时为 25 ms |
| 66.67 % | +0.1667 | 精确的 2:1 三连音摇摆 |
| 100 % | +0.5 | 反拍落到下一拍上 |

`swing_subdivision: 8th|16th` 选择摇摆作用的网格，不写时为 `8th`。

在八分音符网格上，写出位置为 `q` 的音符在 `2q` 为奇数时移动，延迟为 `(swing/100 - 0.5)` 个四分音符。在十六分音符网格上，音符在 `4q` 为奇数时移动，延迟减半。所以在 120 BPM、55 % 时，八分音符移动 25 ms，十六分音符移动 12.5 ms。三连音不在任何一种网格上，保持写出的位置。

要把音符放在网格位置之间，请使用 `grid_offset_beats`（最多 ±0.125 个四分音符）。这个偏移属于写出位置的一部分，摇摆不会改变它。摇摆后的音符保持写出的时值：音符结束和音符开始移动相同的量，所以演奏法不变。

工程的摇摆值决定默认律动。具名乐段可以为它的所有放置覆盖这个值。没有覆盖的乐句、鼓组段落和乐段继承工程的值。没有工程值时，播放是平直的（50%）。

在 **片段** 面板中，清空某个乐段的 **摇摆** 字段，即可让它重新继承工程的值。输入 `0` 会把反拍移到前一拍上。同一面板中的 **Swing 网格** 选择框为整个工程选择八分或十六分音符网格，它设置的就是 `swing_subdivision`。

```ocp
@project "Swung"
  tempo: 120
  swing: 55%

@pattern hats | instrument: drums/acoustic_kit, swing: 66.67%
  hits:
    hihat 1:0 f
    hihat 1:2 f
```

摇摆在四分音符域中与速度和拍号变化叠加。它移动音符、鼓击和写出的延音踏板标记。轨道自动化、音频片段以及总线或主输出的增益自动化保持写出的位置。

在已放置的乐段片段中，被摇摆移到片段开始之前的起音会落在片段开头。被移到片段结尾或更后的起音会被丢弃。循环片段中的音符仍可跨过内部的重复接缝继续发声，但最后的发声会在放置范围内结束。如果某次放置结束时延音踏板仍处于按下状态，播放会补一个踏板释放，时间不早于最后一次踩下和最后一个音符结束。

MIDI 导出按所选 PPQ 写出音符和鼓击摇摆后的位置。明确写出的鼓击时间偏移叠加在摇摆之上。
