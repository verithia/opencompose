# 段落与渲染后的编排 {#sections-and-the-rendered-arrangement}

`@section` 声明编排中一段有名字的时间范围。工程中有段落时，段落决定渲染后的时间线：各段按书写顺序播放，`repeat:` 让一段播放多次。这套模型就是 DSL 已有的 `Section { time_range, repeat, label, flags }`，没有额外语法。

```ocp
@section verse [9:1 - 17:1]
  repeat: 2
  label: "Verse"
  flags: pizzicato
```

循环区域属于播放状态，不是编排的一部分。它在流式走带所播放的书写时间线上循环。开启循环区域既不改变下文所述的展开，也不改变渲染长度。见[标记与循环区域](manual/markers.md)。

## 语义 {#semantics}

- `repeat: N` 让段落播放 `N` 次。不写 `repeat:` 时 N 为 1。校验器会拒绝 0。
- 各段从第一个段落的书写起点开始首尾相接。某一遍的起点等于第一个段落的起点加上之前所有各遍的长度之和。
- 内容容器归属于包含其起点的段落。该段落每播放一遍，就复制并平移一次这个容器。如果某一遍的终点打断了书写时间线，容器会在那里被截断（见[限制](#limits)）。
- 起点在第一个段落之前、在段落之间的空隙中或在最后一个段落之后的内容不会被渲染。编排就是各遍依次相接，所以空隙会消失。
- 段落必须按顺序排列且不能重叠，否则校验器会拒绝。
- `flags:` 指定一种演奏技法：`pizzicato`（别名 `pizz`）、`arco`、`muted`（别名 `con_sord`）、`sul_ponticello`（别名 `sul_pont`）或 `sul_tasto`。它作用于起音落在渲染段落内的音符，音符自己的 `articulation=` 优先。技法通过乐器的演奏法配置（键切换、CC 或参数）传给乐器，所以重复段落的每一遍都带有这种技法。鼓点和音频片段不受影响。
- 如果段落已经以 `repeat` 1 覆盖整条书写时间线（常见的一个段落对应一个部分），展开会把每个位置映射到自身，工程按书写内容渲染。

渲染长度以四分音符计，为 `first_section_start + Σ(span_length × repeat)`。离线渲染以它作为最小长度，所以即使最后一个事件更早结束，段落末尾的休止也会保留。如果最后一个事件的乐器尾音更长，渲染会包含尾音。以秒为单位报告的长度，按展开后的速度映射计算，所以重复段落中保持或移动了速度变化时，报告的是实际播放的时长。

## 哪些内容会移动 {#what-moves}

展开涵盖所有带时间位置的容器：

| 容器 | 归属依据 | 平移内容 |
|-----------|------------|-------|
| 乐句 | `time_range.start`，缺省为 0 | `time_range`（缺省时为 `start_beat`） |
| 片段 | `time_range.start` | `time_range` |
| 轨道内联乐段 | 书写位置 0 | 第一遍保持内联；之后各遍变成生成的顶层乐段上的片段 |
| 鼓 `@pattern` | `time_range.start`，或 0 | `time_range.start` |
| 轨道自动化（整条时间线） | 每个点的位置 | 每个点，展开后排序 |
| 总线/主输出效果器自动化（整条时间线） | 每个点的位置 | 每个点，展开后排序 |
| 自动化片段（带区间的自动化轨道） | `time_range.start` | 每一遍的区间和点（截断处钳住终点） |
| 音频片段 | `time_range.start` | `time_range`（`offset_seconds` 不变；截断处钳住终点） |
| 总线/主输出增益自动化 | 片段起点 | 范围和点，展开后排序 |
| 轨道增益自动化 | 片段起点 | 范围和点（渐强渐弱记号在重复前展开为这种形式） |
| 速度映射点 | 书写位置 | 每一遍都移动该点，所以渲染后的速度随段落重新开始 |
| 拍号映射点 | 书写位置 | 每一遍都移动该点，且每一遍必须从小节开头开始 |

轨道效果器、预设和混音器状态没有时间线位置。每一遍都共用它们，和每个片段共用它们一样。

## 限制 {#limits}

### 按遍截断 {#played-span-cut}

内容按每一遍截断，而且只在渲染时间线不再沿着书写时间线前进的地方截断。

- 截断发生在重复接缝处（下一遍重新从同一书写范围开始），以及被去掉的空隙处（下一遍从更晚的书写时间开始）。在截断点之前开始、会延续到截断点之后的乐句音符、片段乐段音符和鼓点，会在截断点以显式的 `gate_quarters` 释放。在截断点或之后开始的内容，在这一遍中不播放。
- 下一遍接续书写时间线的地方不截断：首尾相接铺满时间线的段落之间，以及重复段落的最后一遍交给下一个书写段落的地方。跨越这种边界书写的音符会完整发声。编排的最后一遍也不截断，因为后面没有其他范围；它的尾音会延续到最后一个事件之后的渲染尾部。
- 音频片段是一种摆放。范围跨过截断点的片段会在截断点被截短。例外是开启了伸缩模式的 `tempo_follow` 片段：它的范围决定了媒体时间如何映射到时间线时间，截短范围会改变媒体的时间。这种片段保留书写时的范围。

截断的原因：一遍是排序和重复所复制的单位，所以同样的书写内容在每一遍中都必须听起来一样。如果内容延续到范围之外，一遍的声音就会取决于后面跟着什么，重复的主歌会带上前一遍主歌的尾音。书写时间连续的地方没有需要纠正的问题，按书写的时值发声。截断是一个 note-off，不会静音任何东西。乐器的释音、轨道的发送以及总线和主输出效果器的尾音会继续衰减，所以截断不会切掉混响尾音。

其他限制：

- 速度和拍号映射随包含其点的段落一起重复，所以每一遍都回到该段落书写时的速度和拍号。`key_map` 是用于人声修音和 MIDI 导出的书写时间映射，不会重复。
- 改变编排的段落不能与 `performance:` 轨道一起使用，后者的时间线以绝对采样计。
- 段落可以重复，但没有跳过或静音的语法。
- 音频片段的裁剪相对于片段本身，所以重复的片段会重放相同的媒体窗口。按遍截断只钳住摆放位置，不改变窗口。
- 自动化片段是容器，所以重复段落会复制整个片段：每一遍都有自己的区间和平移后的点，被截断的一遍会在截断处钳住区间。在区间之外自动化轨道不写入任何值，所以在接缝处数值会跳回片段的起始值，不会在两遍之间渐变。整条时间线的自动化轨道没有区间，它的点会被平移并复制到同一条轨道中，所以会跨接缝插值。
- 增益自动化片段只平移，从不截断。它们的点保持书写时的值。

## 插件看到的映射时间 {#mapped-time-seen-by-plugins}

托管的乐器和效果器在每次 `process` 调用中收到一份时钟上下文，离线渲染和流式播放都是如此。渲染器会在下一个书写的速度或拍号变化处拆分音频块；映射生效期间，还会按 128 帧的源量子拆分。任何一次调用都不会跨越变化点，拆分也不会丢帧或重复帧。恰好落在块边界上的变化从下一次调用开始生效。落在块第一帧上的变化作用于本次调用。

传给插件的数值遵循同一套约定：

- PPQ 是从书写时间线起点算起的四分音符数。它在速度变化处连续，插件不会看到跳变：变化所在的那一帧属于新速度，之前累积的 PPQ 按积分保持不变。
- 一拍是拍号分母所表示的音符。4/4 中一拍是四分音符；6/8 中是八分音符。音乐位置查询根据当前拍号推导拍的边界和小节强拍。
- 小节号在宿主侧从 0 开始（插件看到的第一小节是 0），跨拍号变化连续计数。拍号变化总是开始一个新小节，所以小节不会在变化处合并或重新计数。
- 小节强拍是当前小节第一拍的四分音符位置。新拍号开始时，它移动到书写的变化点。

CLAP 走带事件、VST3 处理上下文和 AUv2 宿主回调使用相同的快照。所以与速度同步的延迟、LFO 或琶音器，在所有托管格式中、离线和流式播放中，算出的时间都相同。

## 播放与图形界面 {#playback-and-the-gui}

离线导出、缓存播放和流式播放都渲染展开后的编排。编辑器时间线按书写位置显示书写的段落。因此重复段落的播放时长会超过书写时间线，定位按书写时钟解析。播放头和定位目标不经过展开映射。
