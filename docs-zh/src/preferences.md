# 偏好设置 {#preferences}

偏好设置是主窗口内的一个对话框，每个主题一页。单击工具栏最右端的**偏好设置**按钮即可打开。按 Escape、单击关闭按钮或单击对话框外部都会关闭它。

侧边栏按以下顺序列出各页：

| 页面 | 内容 |
|---|---|
| 显示 | 语言、主题与变体、界面缩放。 |
| 音频 | 输出设备与格式、输入设备与声道、输入监听、MIDI 输入。 |
| 快捷键 | 快捷键编辑器：搜索命令、重新绑定、恢复默认。 |
| 性能 | 轨道渲染线程数、并行轨道渲染、引擎诊断。 |
| 文件夹 | 用于查找插件和音色的文件夹。你可以添加、移除自己的文件夹，也可以重新扫描。 |
| 存储 | 应用在磁盘上保存的内容，包括大小、清理操作和设置文件。 |
| 网络 | 外发请求使用的代理、连接测试和代理查找。 |
| 外部来源 | 采样服务的凭据及其 API 文档链接。 |
| AI | 服务商、密钥、模型与默认值、权限、编辑目标、工程说明、工具集。 |
| 帮助与关于 | 入门指南、离线手册、版本、许可证、构建信息、诊断包。 |

每次打开某一页，它都会重新读取要显示的内容；离开该页时，它的轮询也随之停止。

## 显示 {#display}

- **语言**提供**跟随系统**和各种界面语言。
- **主题**提供**跟随系统**和各个主题系列。**变体**用来选择该系列中的变体，每个变体都有一张可单击的预览卡片。
- **界面缩放**范围为 70% 到 150%，步长 10%。可以拖动滑块，也可以在数字框中输入数值后按**应用**或回车。**重置**会回到初始缩放：通常是 100%；如果窗口首次打开时小于 1024 × 640 像素，则会更小。

界面缩放作用于整个 WebView，不会改变时间线自身的缩放。

## 音频 {#audio}

音频页包含输出设备、采样率和缓冲区大小，输入设备、**输入声道**、**监听输入**及**监听增益**，输入电平，以及 MIDI 输入和实时输入监听。

打开这一页绝不会请求麦克风权限。页面只读取设备列表和最近一次测得的状态，不会打开采集流。只有发生下列情况之一时，才会开始采集：

- 你选择了输入设备或声道布局；
- 你打开了**监听输入**；
- 有一条录音已待录。

在此之前，输入电平显示**未在采集**。

输入默认为立体声。单声道设备会被复制到两个声道，立体声接口保留原有的立体声像。选择**单声道**则会把输入缩混为一个声道。**监听输入**默认关闭，因为麦克风声音从扬声器放出会产生回授。**监听增益**范围为 −24 dB 到 +12 dB，只在监听打开时有效。

## 性能 {#performance}

**轨道渲染线程数**决定离线渲染使用多少个工作线程。

| 取值 | 含义 |
|---|---|
| 自动 | 每个报告的核心一个工作线程。这是默认值。 |
| 1 到核心数 | 正好使用这么多工作线程。列表最多列到核心数，上限为 64。 |

**并行轨道渲染**用来打开或关闭并行渲染。关闭后，无论线程数设为多少，所有轨道都在一个工作线程上渲染。菜单下方的一行文字会显示下一次渲染将使用多少个工作线程。

应用会保存这项设置，并通过 `OCP_RENDER_THREADS` 传给引擎。引擎在每次离线渲染开始时读取它，所以更改只影响下一次渲染，不影响正在进行的渲染。

展开**引擎诊断**可以看到只读信息：核心数、预读窗口、块大小、首块、输出设备的采样率、上次启动的音频启动延迟及其启动路径，以及首块预算。

## 文件夹 {#folders}

文件夹页列出 OpenCompose 搜索的所有文件夹，分为两个区块：**插件文件夹**，以及存放 SoundFont、SFZ、采样器文件和采样的**音色文件夹**。列表上方的**全部**、**插件**和**音色**标签页可以同时显示两个区块或只显示其中一个，每个标签页都会标出它显示的文件夹数量。每个区块再按文件夹的来源分组：

| 分组 | 所在区块 | 文件夹来源 | 能否在此更改 |
|---|---|---|---|
| 由你添加 | 两者 | 你用**添加插件文件夹…**或**添加音色文件夹…**选择的文件夹。 | 可以。**移除**后不再搜索该文件夹，其中的文件仍保留在磁盘上。 |
| 由 OpenCompose 安装 | 音色 | 音色包的安装文件夹。 | 不能 |
| 标准位置 | 两者 | 各插件格式或音色格式的常用文件夹。 | 不能 |
| 常用位置 | 两者 | 其他音乐软件常用的文件夹，存在时才会搜索。 | 不能 |
| 来自环境变量 | 插件 | `CLAP_PATH`、`VST3_PATH`、`VST_PATH`、`LXVST_PATH` 和 `LV2_PATH`。 | 不能，请修改相应变量。 |
| 来自其他软件的设置 | 插件 | 其他音乐软件设置中要搜索的插件文件夹。 | 不能，请在该软件中修改。 |

分组标题显示分组名称、列出的文件夹数量以及搜索这些文件夹的原因；单击标题可以折叠或展开该分组。每一行显示文件夹的名称、它所在的上级文件夹，以及其中有多少个插件，或有多少个乐器和采样。这台电脑上不存在的标准位置或常用位置不会列出，区块下方的一行文字会给出它们的数量。你添加的文件夹如果已不存在，仍会留在列表中，并显示**未找到**。所有位置的完整清单见[插件](manual/plugins.md)。

单击某一行即可选中它。列表底部的信息栏随即显示该文件夹的名称、完整路径、来源及被搜索的原因，以及其中的内容。**在文件管理器中显示**会打开该文件夹所在的位置；文件夹已不存在时，这个按钮不可用。再次单击该行即可取消选中。

添加插件文件夹后，页面会保存它、重新统计各文件夹，并在后台开始扫描插件，这样该文件夹中的插件就会出现在插件浏览器中。你添加的音色文件夹中可以有 SoundFont、SFZ 或采样器文件，也可以有音频采样（WAV、AIFF、FLAC、OGG 或 MP3），或者两者都有，所以只有采样的文件夹也可以添加。这一点只适用于你自己选择的文件夹，无论是在这里还是在首次启动向导中选择；由助手注册内容库时，文件夹中仍必须有乐器文件。

应用拒绝某项更改时不会写入任何内容，页面会说明原因：

- 该文件夹不存在；
- 该文件夹已在搜索范围内；
- 该文件夹已不在你的列表中；
- 插件文件夹列表已满（最多 32 个）；
- 无法读取已保存的文件夹列表，因此保持不变；
- 该文件夹中既没有音频采样，也没有 SoundFont、SFZ 或采样器文件；
- 无法保存更改。

**重新扫描**会再次读取所有插件，包括之前无法读取的插件，然后统计音色文件夹。页面会像首次启动向导那样显示这两个步骤的进度，扫描结束后插件、乐器和采样的总数随之更新。

## 存储 {#storage}

存储页上的每个大小和数量都是从磁盘读出的，所以它反映的是磁盘上实际有什么，而不是工程认为自己用了什么。大多数区块都有自己的**扫描**按钮，可以单独重新统计某个区块，不必等其他区块。

| 区块 | 显示内容 | 操作 |
|---|---|---|
| 渲染归档格式 | 完整试听渲染的格式：WAV，或 128 到 320 kbps 的 MP3。 | 选择格式。 |
| 编辑历史 | 当前工程历史的大小。 | 设置达到多大时显示提示。 |
| 项目数据 | 每个工程和工作区文件夹的编辑历史、AI 笔记、恢复副本和对话，附大小以及“已不存在”或“即将删除”状态。 | **删除**，仅对文件或文件夹已不存在的数据提供。 |
| 对话 | 每个工作区保存的对话，以及它们共用的试听片段和渲染。 | **删除**单个对话、**清除旧对话历史**、**清空试听音频**、**打开目录**。 |
| SoundFont | 已安装的音色包及其文件夹中的文件。 | **打开目录**。 |
| 插件 | 搜索文件夹中的插件文件，按格式计数，并显示每个文件夹的大小。 | 每个文件夹的**打开目录**，以及打开文件夹页的**管理文件夹…**。 |
| 片段音频缓存 | 解码后的音频、处理后的音频，以及人声分析与烘焙结果（预算 1 GiB）。 | **清理未使用的片段音频**会同时清理这三项。 |
| 采样缓存 | 当前工程 `media/samples` 文件夹中的文件数和字节数。 | **打开目录**、**清空**。 |
| 其他应用数据 | 辅助运行时、插件目录、预设库、采样服务、试听暂存、响度补偿和诊断日志。 | **打开目录**。 |
| 设置文件 | 设置文件的路径。 | **打开目录**、**导出偏好设置…**、**导入偏好设置…**。 |

文件或文件夹已不存在的项目数据会在 30 天后由启动时的清理任务删除。你也可以提前用**删除**手动删除。参见[磁盘存储](storage-layout.md)。

采样缓存区块中的**清空**会删除当前工程 `media/samples` 文件夹中的所有文件，但保留文件夹本身。它不会动工程文件、存放在该文件夹之外的音频片段，也不会动其他工程。预设引用的采样会从工程中丢失，所以应用会先询问。从未保存过的工程没有媒体文件夹，这时区块会提示你先保存工程。

设置文件是 `~/.opencompose/gui-settings.yaml`。如果这个 YAML 文件还不存在，应用会读取旧的 `gui-settings.json`，并在下次保存时写成 YAML。**导出偏好设置…**和**导入偏好设置…**读写的是你另外选择的一个文件，参见[偏好设置包](../preferences-bundle.html)（英文）。

### 独立的配置档案 {#separate-configuration-profiles}

在启动应用或 `ocp` 之前设置 `OPENCOMPOSE_CONFIG_DIR`，就可以使用一个独立的配置文件夹。不设置时，配置文件夹是 `~/.opencompose`。GUI 与音频偏好设置、保存的 AI 对话、预设以及该文件夹下的其他文件都会放进你指定的文件夹。应用不会把现有设置复制过去。用 `--debug` 或 `--perf` 生成的诊断日志写入档案内的 `logs/`；没有档案时，写入平台的日志文件夹。

这个值必须是非空的绝对路径，且其父文件夹已经存在。档案文件夹本身请交给 OpenCompose 创建。在 macOS 或 Linux 的 shell 中：

```sh
mkdir -p "$HOME/.opencompose-profiles"
OPENCOMPOSE_CONFIG_DIR="$HOME/.opencompose-profiles/review" ocp validate song.ocp
```

在 Windows 上，请选择 `%LOCALAPPDATA%` 下的文件夹，并且 `%LOCALAPPDATA%` 本身解析后必须位于 `%USERPROFILE%` 之内。OpenCompose 会先解析已存在的上级文件夹再做检查，其他位置一律拒绝。Windows 上的档案沿用用户配置文件继承的权限。

OpenCompose 会给自己创建的档案文件夹做标记，以便日后复用。它会拒绝不是由它创建的现有文件夹、损坏的标记、本身是符号链接的档案文件夹，以及权限不安全的 Unix 档案，而且绝不修改该文件夹的权限。在 Unix 上，它创建的档案文件夹权限为 `0700`，标记文件为 `0600`。档案出错时启动会中止，不会退回默认文件夹。进程在退出前一直使用同一个档案，要切换请重新启动。

切换档案前请先退出正在运行的实例。档案不会改变应用的单实例标识、WebView 存储、操作系统凭据存储、插件安装文件夹或工程位置，也不会改变 `HOME` 或其他应用的设置。

## 网络 {#network}

**代理**决定发往采样市场、插件索引和 AI 服务商的外发请求如何连接：

| 选项 | 设置值 | 含义 |
|---|---|---|
| 跟随系统 | `system` | 使用操作系统的代理。这是默认值。 |
| 使用此代理 | `manual` | 使用**代理地址**中的地址。 |
| 直接连接 | `none` | 不使用代理。 |

这个选项以 `network.proxyMode` 保存在设置文件中，地址保存为 `network.proxyUrl`。没有可用地址时，应用不接受**使用此代理**。

**测试连接**会通过所选线路请求 `https://api.openverse.org/v1/`，并显示耗时和 HTTP 状态码，或者错误信息。

**查找代理**会用插件索引检测已保存的线路、直接连接和常见的本地代理端口。它逐条列出每条线路的结果和耗时，单击**使用**即可保存一条可用的线路。只有能对索引主机建立 CONNECT 隧道的本地端口才算代理，所以同一端口上的网页服务器，或者连不上索引的代理，都不会出现在可选项中。首次启动向导或素材库获取索引失败时也会运行同样的检测，你可以在那里先应用一条可用线路，再重试获取。

## 外部来源 {#external-sources}

这一页把采样服务的凭据保存在操作系统的凭据存储中：

- Freesound：一个 **API 密钥**，外加 **Freesound 原始音质**，用来连接你的 Freesound 账户以下载原始文件；
- Jamendo：一个**客户端 ID**。

每个服务都附有 API 文档链接。**公共搜索 API** 链接到 Openverse、Wikimedia Commons 和 Internet Archive 的文档，这几个服务不需要凭据。参见[采样](samples.md)。

## AI {#ai}

AI 面板中的**服务商设置**按钮会直接在这一页打开偏好设置。

服务商、模型和默认值的修改在你按下**保存设置**之前都只是草稿，表单上方的一行文字会提示这一点。权限、编辑目标和工具集会立即生效。**测试连接**测试的是已保存的服务商和模型，所以请先保存修改。删除服务商或已保存的密钥前，应用会先询问。

切换到其他页面时草稿会保留。带着未保存的 AI 修改关闭偏好设置时，应用会询问是否放弃这些修改；如果选择保留，偏好设置不会关闭。

密钥永远不会写入设置文件。它保存在操作系统的凭据存储中，页面只显示是否已保存密钥。

## 帮助与关于 {#help--about}

- **入门指南**会关闭偏好设置，重新打开首次启动向导。**音频**和**快捷键**按钮分别打开这两页。
- **用户手册 · 离线 · 英文**在应用内显示用户手册。
- **版本**取自构建，**支持的 DSL 版本**取自解析器 crate，因此两者都与正在运行的程序一致。
- **许可证**为 AGPL-3.0-or-later。**Git 仓库**会打开 `https://github.com/verithia/opencompose`。
- **构建信息**显示源码修订号、构建配置、操作系统和架构。
- **致谢和许可证**包含 AGPL 全文、语言组件的 MIT 和 Apache-2.0 全文，以及第三方软件和资源的声明。
- **导出诊断信息…**会写出[诊断](../diagnostics.html)（英文）中介绍的支持包。

## 资源浏览器 {#the-resource-browser}

**偏好设置**旁边的**浏览**按钮会打开**资源**浮层，其中有三个标签页：

- **插件**列出免费插件目录，与素材库中的列表相同。
- **采样**搜索采样市场，与底部面板的采样模式是同一个面板。
- **效果器**按类别列出内置设备，以及插件扫描找到的效果器插件。**添加到选中轨道**会把其中一个加到选中的轨道上。

这个浮层不会改变底部面板的模式。

## 界面缩放与工具栏 {#interface-scale-and-the-toolbar}

界面缩放越大，工具栏可用的 CSS 像素就越少。工具栏把**偏好设置**和**浏览**放在走带和文件控件所在的条带之外，所以这两个按钮始终留在窗口内。条带始终只有一行高，宽度不够时可以横向滚动。窗口宽度低于 1180 CSS 像素时，按钮文字会先隐藏、间距会先缩小，然后才会隐藏控件。

`npm run layout-check` 会在无头 Chrome 中、1400 像素宽的窗口里，以 150% 和 200% 渲染工具栏；如果有按钮跑出窗口或它所在的滚动条带，检查就会失败。整个工具栏都是窗口拖动区域，所以可以从任意空白处拖动窗口。
