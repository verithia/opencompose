# 主窗口 {#the-window}

桌面应用基于 Tauri 2 和 SolidJS 前端构建。前端源码位于 `crates/oc-gui/frontend/`，Rust 后端位于 `crates/oc-gui/frontend/src-tauri/`。

## 布局 {#layout}

```
┌──────────────────────────────────────────────────────────────┐
│ toolbar: transport, position, tempo, meter, file, MIDI, render│
├───────────────────────────────────────────────┬──────────────┤
│ Timeline (always visible)                     │  Sidebar:     │
│  track headers + ruler + clips                │  DSL          │
├───────────────────────────────────────────────┤  Plugins      │
│ Bottom panel: Clips | Piano Roll | Presets |   │  Store        │
│ Mixer | Drum Kit | Samples | History |         │  AI           │
│ Inspector                                     │               │
├───────────────────────────────────────────────┴──────────────┤
│ status bar: state, track/bus count, selection, project, time  │
└──────────────────────────────────────────────────────────────┘
```

上方是时间线，下方是底部面板：**片段**、**钢琴卷帘**、**预设**、**混音器**、**鼓组**、**采样**、**历史**和**检查器**。右侧边栏有 **DSL**、**插件**、**素材库**和 **AI** 四个标签页。

拖动时间线与底部面板之间的分隔条可以调整两者的高度。侧边栏左边缘有拖动手柄，宽度可在 220 到 600 px 之间调整。**检查器**标签只在有片段在其中打开时才出现在底部标签栏里。

## 走带 {#transport}

工具栏上有停止和播放/暂停按钮、拍位置读数、速度输入框（20–999 BPM）和拍号菜单。按 **Space** 开始或停止播放。单击时间线标尺可以拖动定位。播放时时间线会跟随光标滚动，直到你手动滚动时间线为止；下一次播放时会重新跟随。

Space 作用于你最后一次按下指针的区域。如果那是底部面板，并且正显示**预设**视图、选中了一个预设，Space 会试听这个预设，不影响走带。在其他区域，Space 播放或暂停时间线。底部标签栏处于活动区域时，边缘会显示强调色。试听不会移动时间线光标，也不会启动或停止走带。

**写入自动化**位于**走带设置**弹出面板中。它是所有写入自动化点的界面共用的一个开关，没有默认快捷键，你可以在**偏好设置 > 快捷键**中为它绑定一个。打开后，按住旋钮就会录制曲线。走带运行时，每个网格单元记录一个点；走带停止时，一次手势在播放头处写入一个点，所以停止时按钮仍然可用（提示信息里也写明了这一点）。整个手势是一条撤销记录，状态栏会报告结果，例如 `Recorded 12 points on filter.cutoff (1/16 grid).`。关闭时，拖动旋钮只是普通编辑，不会创建自动化轨道。还没有自动化轨道的参数会在录制第一个点时得到一条。

工具栏上还有文件操作（新建、打开、保存、另存为、移动工程）、MIDI 导入与导出、离线渲染为 WAV、导出分轨、**AI** 按钮和**偏好设置**按钮。**偏好设置**会打开一个窗口，包含以下页面：**显示**（主题系列与变体）、**音频**（输出设备和实时 MIDI 输入）、**快捷键**（快捷键列表）、**性能**、**存储**、**网络**、**外部来源**、**AI** 和**帮助与关于**（导出诊断信息）。

工程从创建那一刻起就有对应的文件。**新建工程**会询问保存位置，在那里写入文件，并拒绝已有文件的路径。没有打开工程时，起始界面会让你打开或新建一个。**移动项目**为打开的工程换一个文件，并把编辑历史和备份一起带走，旧位置不留任何东西。

同一时间只有一个进程能打开某个工程。如果另一个 OpenCompose 进程已经打开了它，打开操作会被拒绝，你当前的工程保持打开，窗口会告诉你是这种情况。已保存的对话也遵循同样的规则：打开另一个进程占用的对话时，AI 助手继续显示当前的对话。

## 编辑历史 {#edit-history}

每个工程的编辑历史保存在应用数据文件夹的 `<config>/history/<path key>/` 下，所以撤销可以回到之前会话中的编辑。`.ocp` 文件旁边不会写入任何东西。`<config>` 是应用配置目录，即 `~/.opencompose`，或者 `OPENCOMPOSE_CONFIG_DIR` 指定的目录。路径键是工程规范路径的 SHA-256 的前 8 个字节，以十六进制表示。

该文件夹包含四个文件：

- `project.json` 是标识文件：版本、工程的规范路径和文件内容的 SHA-256。
- `entries.jsonl` 每行一条记录。
- `index.bin` 是当前的线性历史。
- `state.json` 保存光标、当前所在记录的 id 以及该记录对应的文档。

每条记录都写明作者：你、某个具名对话中的智能体、外部客户端，或者在 OpenCompose 之外对文件做的修改。记录还包含其补丁描述的类型化更改，以及一个原因字段，用来标记由旧版对话恢复写入的记录。召回只移动光标，不写入记录。

按 **Mod+Z** 和 **Mod+Shift+Z** 在历史中前后移动。状态栏会根据记录中的类型化更改，用应用当前的语言描述这一步撤销或重做了什么，并写明作者。智能体的一轮正在运行或持有批处理时，撤销会等待，状态栏显示 `Agent is editing the project, cannot undo.`

底部面板的**历史**标签按从新到旧列出记录，每次 64 条；**加载更早的条目**显示其余部分。单击一条记录，工程会移动到该记录之后的状态。已撤销的记录会一直留在列表中，直到新的编辑取代它们。

该标签还显示历史占用的空间。**清除较早历史**会保留你选择的若干条最新记录，询问后删除其余部分。之后撤销最多只能回到保留的最早记录。你撤销过的记录永远不会被清除。历史超过**偏好设置 > 存储**中设定的大小（默认 1 GB）时，该标签和状态栏会提示清理。没有你的确认，什么都不会被清除。

应用按路径查找工程的历史。如果某个文件的路径没有对应的历史，应用会把文件的 SHA-256 与每份历史的标识文件比对，工程文件已不存在的历史会跟随这个文件。所以在应用之外移动或复制的文件仍能保留历史：旧文件还在时复制历史，旧文件已不在时移动历史。用**新建工程**创建的工程从全新的历史开始，不会接收其他文件的历史。

**移动项目**会把历史、AI 笔记、限定在工程文件夹内的对话以及恢复副本一起移到新路径，旧路径不留任何东西。**另存为**会复制历史和 AI 笔记，对话和恢复副本留给旧文件。

工程文件或工作区文件夹不存在后，它的数据会保留 30 天，然后由应用启动 60 秒后运行的清理任务删除。位于未挂载卷上的文件不算不存在。打开中的工程的数据和正在运行的对话永远不会被删除。

**偏好设置 > 存储**列出每个工程和文件夹的数据（历史、AI 笔记、恢复副本和对话），以及大小和状态（已不存在或即将删除）。只有已不存在的数据才有**删除**按钮。该页面还会显示其他应用文件夹和片段 PCM 缓存。参见[磁盘存储](../storage-layout.md)。

## 时间线 {#timeline}

轨道头包含颜色条、名称（双击可重命名）、乐器或预设标签、**▸ 试听**、**M**（静音）和 **S**（独奏）。

片段是轨道上的色块。单击色块选中它的乐段；双击打开**检查器**，显示片段的来源和位置，音符片段还会附带钢琴卷帘。

具名乐段片段、内联乐句和内联鼓乐段的拖动方式相同。色块在共享网格上跟随指针，松开时吸附，拖到另一条轨道上就会移到那条轨道。拖动右边缘可以改变结束位置，起点保持不动。按住 Alt 拖动可以复制具名片段。按 Escape 取消拖动，工程不会改变。

把指针悬停在色块上可以查看详情。名称下方依次是类型和轨道、小节范围、以小节、拍和时间表示的长度、音色以及音符或击打数。只有某项与默认值不同时，才会多出一行状态：移调、摇摆、颜色、静音或独奏、增益或声像、选中状态。音频片段还会列出偏移、拉伸、源文件、采样率和声道数。拖动或调整大小期间卡片会隐藏，下次悬停时显示色块的新状态。

右键单击片段打开菜单：打开编辑器、重命名、复制、剪切、粘贴、复制一份、在播放头拆分和删除（**Mod+Z** 可以恢复删除的片段）。内联乐句和内联鼓乐段的菜单较短（打开编辑器、复制、粘贴），音频片段提供拆分和删除。右键单击轨道可以重命名、添加轨道、在播放头处创建乐段、打开混音器或使用 MIDI 操作。

每个菜单的第一行都是它所操作对象的名称。打开菜单不会选中该对象，也不会移动播放头，所以即使选中的是别的东西，菜单也只作用于你右键单击的对象。只有主按键会选中、拖动或调整大小；次按键单击（包括 macOS 上的 Ctrl-单击）只打开菜单。**打开编辑器**是唯一会同时选中片段的菜单项。

片段菜单和 **Delete** 通过同一条路径作用于所有片段类型。乐段片段、音频片段和自动化块都由同一个片段池命名。该类型支持的手势会执行这一类型自己的命令；不支持的手势会被禁用并说明原因。音频片段不能复制一份，整条时间线的自动化轨道没有区间，无法移动、调整大小、复制、拆分或删除。后端拒绝某个手势时，状态行会原样显示它给出的消息。

选中的片段支持剪切、复制、粘贴、复制一份和 Delete（见[键盘快捷键](#keyboard-shortcuts)）。工程中有段落或调性标记时，标尺上方会有一条细信息条显示它们，同一轨道上重叠的片段会被标出。

用时间线底部的按钮或 **Mod+滚轮**缩放，范围为每拍 6 到 120 px。

### 音频片段 {#audio-clips}

音频片段显示波形和裁剪手柄，可以在播放头处拆分，并精确放置在它所在的帧上。

要单独听一个片段，右键单击它并选择**预览片段**。你会听到它当前的片段处理和混音器处理，不含同一轨道上的其他片段。**Space** 在预览自己的位置上暂停和继续。

要改变速度或音高，双击片段，或者从菜单中选择**速度与音高…**：

1. 以倍数设置播放速度、以带小数的半音移调，或者让源音频适应片段在时间线上的长度。
2. 持续性的素材选**音乐**，起音尖锐的素材选**打击乐**。
3. 打开**移调时保留共振峰**来补偿移调，或者设置**共振峰偏移**来改变人声音色。
4. 选择**应用**。

这项编辑保留原始文件和片段在时间线上的边界。要对比，打开**旁通处理**并选择**应用**：你会在同一片段范围内听到原始音频，处理设置仍然保留。

变速标记把源时间映射到目标时间，两者都从音频起点开始计算。输入这两个时间即可添加标记。标记旁的**吸附**会把它的源时间移到附近的起音处，目标时间保持不变。拖动可见的标记可以在时间线上移动它的目标位置。

要同时拉伸和调整大小，选中片段后拖动它的 ↔ 手柄，或者按住 Alt/Option 拖动右边缘。直接拖动边缘是裁剪。裁剪或拆分一个已适应其范围的片段时，会保留适应时得到的速度。

### 画面时间码 {#picture-timecode}

右键单击时间线标尺，选择**画面时间码**。设置画面的帧率和工程起点处的时间码，格式为 `HH:MM:SS:FF`（29.97 fps 的丢帧时间码用 `HH:MM:SS;FF`）。帧标签按画面剪辑中显示的值输入。

- **读取播放头**显示离播放头最近的画面帧。
- 反过来，输入一个标签，选择**转换**，再选择**移动播放头**。播放头会按当前的速度映射移到该帧的时间，包括网格线之间的位置。
- **保存项目时间码设置**会把帧率和起点标签存入工程，保存并重新打开后仍然有效。**清除已保存的设置**会删除它们。这两项操作都可以撤销。

### 自动化行 {#automation-rows}

每条轨道都可以在下方显示自己的自动化。轨道头中的 **A** 按钮（在 **M** 和 **S** 旁边）以及轨道菜单中的**显示自动化**用来展开和收起这一区域。它默认收起，展开状态在本次会话中按轨道分别保存。

每条自动化轨道占一行。这一行用折线画出各个点，并标出名称。行头单元格重复名称，显示目标类型（**效果**、**音色**或**控制**），还有一个单独的 **M** 按钮。`pluginparam_…` 自动化轨道会显示它所编码的参数名，所以合成器或插件的自动化轨道读起来就像它所控制的旋钮。

带区间的自动化轨道（`automation: … [3:1 - 5:1]`）会把区间画成一个块，方便你看出它写入的范围。没有区间的是整条时间线的自动化轨道：这一行带条纹且没有块，因为它从第一个点一直写到工程结束。

操作自动化块的方式和操作片段一样：

- 拖动块可以连同其中的点一起移动。一个虚影跟随指针，位置以 1/16 为下限吸附到共享网格，松开时写入，作为一条撤销记录。
- 拖动起始或结束边缘可以调整大小，另一侧边缘保持不动。
- 按住 Alt 拖动会复制指针下的块，与片段轨道使用相同的复制修饰键。
- 按 Escape 取消拖动，工程不会改变。
- 右键单击块或它所在的行，可以选择**复制到播放头**、**复制**、**在播放头拆分**和**删除**。**复制**把副本放在块的紧后方；**复制到播放头**把副本放在播放头处。**在播放头拆分**要求播放头位于块内部，且距两端至少一个十六分音符，拆分后的两半在接缝处衔接于块在该点写入的值。**删除**会删除这条片段式自动化轨道，选中块后按 **Delete** 效果相同。

如果移动、调整大小、复制或拆分会与同一目标上的另一条自动化轨道重叠，操作会被拒绝。状态栏会写出两个区间，块留在原处。整条时间线的自动化轨道没有块，所以这四个菜单项在那里被禁用，并提示**该轨道控制整条时间线，片段手势需要一个区间。**

效果、音色和控制三类自动化轨道都支持这些手势。使用独立 tick 网格的自动化轨道（`automation: … [ppq=N]`）不支持，因为这些手势基于工程的记谱网格。

编辑点的方法：

- 双击行，在指针处添加一个点。垂直位置决定数值，时间以与片段位置相同的 1/16 下限吸附到共享网格。网格更细时，底部会注明这个下限。
- 拖动点可以在两个方向上移动它。一个虚影跟随指针，水平位置吸附到网格，松开时写入，作为一条撤销记录。
- 单击点即可选中。**Delete** 或 **Backspace** 删除选中的点，点的菜单中也有**删除点**。
- 右键单击点，可以选择四种段曲线之一（**线性**、**阶梯**、**半正弦**、**柔和**），或者选择**张力…**，输入柔和段使用的 0–1 混合值。

静音的自动化轨道显示**该轨道已被静音。**，并拒绝所有编辑；添加、移动或删除点时会报告这个原因，不写入任何内容。点击它的 **M** 按钮可以取消静音。没有自动化的轨道显示**该轨道还没有自动化。右键单击旋钮并选择“创建自动化轨道”。**

总线和主输出的自动化没有对应的轨道行，所以它们的行排在最后一条轨道之后，位于一条写明所属对象的横条下方。只要还有自动化轨道，它们就一直可见。

同一条自动化轨道也出现在设备架的**自动化**列表中，那里有它的模式、平滑、曲线和 LFO 控件。点的位置和数值在时间线的行上编辑。

## 速度与拍号轨道 {#tempo-and-meter-lane}

标尺头部的**速度**标签会在轨道上方打开一条两行的轨道，上一行是速度点，下一行是拍号变化。工程中已有速度或拍号映射时，这条轨道默认展开；添加第一个点时会展开；两种映射都清空后会收起。收起时它不占用时间线高度。固定的头部显示播放头处的速度和拍号。

- 双击某一行，在吸附后的位置添加一个点；或者右键单击该行，选择**在此添加速度点**、**在此添加拍号变化**或清除项。新点的初始值等于该位置当前生效的值，所以在你编辑之前，添加它不会改变任何东西。
- 水平拖动点。速度点吸附到共享网格，拍号变化吸附到小节起点。Alt 是时间线的复制修饰键，所以这里没有关闭吸附的修饰键。小节编号来自拍号映射，所以标尺对小节的编号与引擎的计数一致。
- 双击点，或者右键单击它并选择**设置数值…**，可以输入数值。速度可接受 20–400 BPM。拍号分子为 1–32，分母为 1、2、4、8、16 或 32。无效的数值和重复的位置会被拒绝，工程保持不变。
- Delete 删除获得焦点的点，右键菜单还可以清空整个映射。清空所有速度点后回到工程 BPM；清空拍号变化后回到工程拍号。
- 用键盘时，按 **Tab** 移到这条轨道或某个点上。**←/→** 把选中的点移动一个网格步长（拍号变化每次移动一个小节）。**↑/↓** 把速度点改变 1 BPM（按住 Shift 为 10），或把拍号分子改变 1。**Enter** 编辑数值，**Delete/Backspace** 删除点，**Esc** 取消选择。

每次编辑是一条撤销记录，也算一次未保存的更改。这两种映射在 `.ocp` 中保存为 `tempo_map` 和 `time_sig_map`，走带、网格和片段位置都通过它们解析。

## 钢琴卷帘 {#piano-roll}

钢琴卷帘编辑选中的乐段，或者你从乐句或时间线上打开的片段。它的工具栏有两个工具和一个缩放控件（每拍 10–200 px，也可以用 **Mod+滚轮**）。

卷帘显示打开的片段。左边缘是片段的第一拍，片段边界标出片段的结束位置（不含该位置）。鼓网格可以显示超出边界的已编写击打，方便你继续编辑它们。

小节编号保持绝对值：从第 9 小节开始的片段，左边缘标为“9”。从小节中间开始的片段，会在左边缘显示不完整的那一小节，并在下一小节真正开始的地方画出第一条完整的小节线。

绘制、拖动、调整长度、微移和复制都会让音符起点保持在片段内。一拍长的片段宽度正好是一拍。只有长度为零的范围才会退回到一个网格步长，所以画布不会塌缩。

使用**选择工具**时，拖动音符可以移动，拖动音符边缘可以调整长度，在空白处拖动可以框选，Shift-单击可以把单个音符加入或移出选区。使用**绘制工具**时，单击即可添加音符。两种工具下，Delete 或 Backspace 都会删除选中的内容。

### 鼓轨道 {#drum-lane}

预设为鼓组（`builtin.drumkit`）的鼓乐段会得到一条鼓轨道，每个打击垫占一行，按鼓组自己的顺序排列。每行标有打击垫名称，工具栏在乐器旁显示鼓组名称。鼓组没有声明的音符会得到一行 `Other <n>`，其中 `<n>` 是它的 MIDI 音符号。鼓组没有命名、也没有任何击打使用的半音不占一行，所以鼓轨道只显示鼓组的打击垫，而不是 72 行。普通鼓轨道保留 General MIDI 的各行。

击打放在当前网格上，包括三连音和 1/32 音符。DSL 存储一个十六分音符锚点，并把精确的网格偏移量以四分音符为单位存为 `grid_offset_beats`，最大 ±0.125。写入的位置决定击打是否落在片段内；摇摆和可选的 `timing_offset_beats` 再改变你实际听到的起始时刻。放在 `Other` 行上的击打会把该行的 MIDI 音符写入 `midi_note`，这样鼓组就会演奏包含该音符的打击垫。

标记和力度条把每个已编写的击打各显示一次，包括它的显式时间偏移。空心显示的击打，在应用片段的滑移、重复、摇摆和时间边界之后，在这个位置上没有会被播放的起始时刻。你仍然可以选中空心击打并编辑它的力度。

### 菜单与按键 {#menus-and-keys}

右键单击（macOS 上为 Ctrl-单击）会为指针下的对象打开菜单，不改变其他任何东西。在音符上打开音符菜单（复制、在播放头粘贴、复制一份、删除、力度、静音、装饰音），在鼓击打上打开击打菜单，在空白网格上打开网格菜单（在此绘制音符、在此粘贴、网格 1/4–1/32）。菜单第一行写出音符（音高和力度）或位置（音高、小节和拍；在鼓轨道上为打击垫名称）。击打菜单写出并删除指针下的那个击打，右键单击同时也会选中它，所以 Delete 作用的就是菜单显示的那个击打。

只有主按键会选中、绘制或拖动定位。次按键单击不会选中音符、开始框选或移动播放头。

Delete 或 Backspace 删除选区，**Mod+D** 复制选区，**Mod+A** 选中全部音符，**Esc** 取消选择。左/右方向键微移一个网格步长，Shift+左/右微移一拍。

## 混音器 {#mixer}

混音器面板左侧是选中节点的检查器，右侧是路由视图，总线图上方有一条工程级的路由工具栏。总线图显示拓扑结构，工具栏用来创建总线，检查器编辑选中的节点和连接。

总线图左列是轨道，中间是总线，右侧是主输出。每个连接画成一条曲线：实线表示主输出或总线路由，虚线表示发送。单击节点可以查看它，单击连接可以编辑它。也可以用键盘的 `Enter` 或 `Space` 按下连接。单击背景会取消选择，拖动背景可以平移视图。

要添加总线，在工具栏的总线输入框中输入名称，或者留空以得到第一个可用的 `Bus N`。新总线路由到主输出并被选中。要添加轨道，把一个预设拖放到混音器上。

选中连接后，检查器中源节点控件的下方会出现一张卡片。用 `To` 重新指定连接的去向：轨道唯一的主输出、一个发送或一条总线路由。发送还会显示 dB 电平、`PRE`/`POST` 取信号点、输入声像和删除按钮。`Escape` 离开卡片；`Delete` 删除连接，焦点回到源节点。

在通道控件旁边，轨道可以添加到总线的发送，总线可以添加到主输出或另一条总线的路由。

删除总线的按钮位于通道详情下方的总线操作卡片中。没有被使用的总线会立即删除。仍被轨道输出、发送或总线路由使用的总线会被拒绝删除，错误信息会列出这些引用。随后确认卡片会提供先重新路由再删除的选项：轨道输出改回主输出，发往该总线的发送被移除，路由到它的总线改回主输出。

通道选择器下方的节点详情显示推子、声像、`M` / `S` / `SAFE` / `Ø`、效果链、发送列表（CLAP 和 VST3 乐器还有辅助源选择器）以及总线路由列表。

每个控件在一次手势中只提交一次，所以一次推子移动、一次发送编辑或一次连接重新指定就是一条撤销记录。参见[混音器路由](../mixer-routing.md)。

## 设备架 {#device-rack}

每条轨道、每条总线和主输出都有一条效果链。`+` 打开内置设备选择器，展开某个槽位就会显示该设备的面板。槽位的右键菜单有**旁通**（仅限定义了旁通的设备）和**移除效果器**。

动态 EQ 会打开完整的曲线编辑器。拖动节点设置频率和增益，在节点上滚动滚轮调整 Q，按住 Alt 拖动动态频段设置它的范围，双击恢复默认。方向键用于微调。每个频段都有独奏，通道视图可以在 `All`、`L`、`R`、`M` 和 `S` 之间切换。

固定 EQ 和被动 EQ 有各自的曲线视图。播放音频时，设备面板可以显示增益衰减量，参数 EQ 可以绘制实时频谱。插件效果器显示原始参数列表。

## 音色补丁编辑器 {#patch-editor}

选中 OpenSynth 预设会打开合成器工作台。它有以下视图：**音色**（包含**振荡器**、**滤波器**和**振幅**三个页面）、**调制**、**效果**和**发声**；还有一个预设输入框，点击后打开出厂音色和用户库浏览器；一个**加载**按钮，用来导入外部预设文件；一个 `⋯` 音色补丁菜单；一个**紧凑**/**展开**切换按钮；以及一个试听键盘。编辑器写入预设的 `params`，所以每次编辑都是可撤销的工程更改。详见 [OpenSynth](synth.md)。

把指针悬停在旋钮上或让它获得焦点，可以读取它的数值。按住旋钮，向上移动指针增大数值，向下移动减小数值；按住 Shift 可以更精细地调整。侧边指示器会跟随手势，你不需要把指针移到它上面。松开即提交编辑。鼠标滚轮也可以调节旋钮。用键盘时，让旋钮获得焦点，然后使用方向键、Home 或 End。Enter 或 Space 打开纵向编辑器，Escape 关闭它。双击恢复参数的默认值。

音色补丁输入框显示工程预设的名称。名称后面较小的标签写明它是从哪个音色补丁加载的（出厂音色、用户库条目或导入的文件名），这个标签会保存在 `.ocp` 文件中。`⋯` 菜单用来管理音色补丁：

- **重命名…**重命名工程预设，并在同一个撤销步骤中改写所有轨道、乐段和 `extends:` 引用。
- **复制**和**另存为…**会创建一个独立的副本，并让使用者改用它，所以编辑副本不会影响原件。
- **保存到音色库…**把整个音色补丁（参数、效果链和来源信息）存到 `~/.opencompose/presets` 下，供其他工程使用。它依赖的 OpenSynth 波表和采样会被复制到音色库中，所以源工程可以独立移动。

浏览器列出出厂音色库和一个**用户库**分区，两者的搜索和试听方式相同；搜索也会匹配音色库标签。加载一行会替换整个音色补丁（参数、效果链和来源标签），并重置该行没有声明的所有键，作为一条撤销记录。试听和重置规则见 OpenSynth 一章的[出厂音色](synth.md#factory-patches)。

## 插件浏览器 {#plugin-browser}

侧边栏的**插件**标签列出扫描到的 CLAP、VST3、VST2、AU 和 LV2 插件以及内置素材。它有搜索框、格式和类型筛选、**重新扫描**按钮，以及**检查工程**，用来报告工程引用了但应用找不到的插件。**添加预设**会用选中的来源创建一个工程预设。

LV2 和 VST2 插件没有应用内编辑器。LV2 控制端口在 DSL 或预设编辑器中作为预设的 `params` 编辑，VST2 参数在预设编辑器中编辑。

**素材库**标签会在单独的窗口中打开外部插件、采样、SoundFont 和预设网站，并列出随附的免费插件目录。

## DSL 编辑器 {#dsl-editor}

按 **D** 打开 DSL 侧边栏，它以语法高亮的文本显示整个工程。**Mod+Enter** 解析并应用文本。解析出错时会在行内显示错误，不应用任何内容。每次应用是一条撤销记录。

## AI 助手 {#ai-panel}

侧边栏的 **AI** 标签是一个围绕当前工程的聊天界面。它有服务商设置（端点、模型、密钥或登录）、**描述编排**、**添加混响总线**、**添加鼓点**和**改善混音**等快捷提示、工具日志和差异视图。

**工程编辑权限**决定智能体的编辑如何生效。选择**询问**时，每次对工程 DSL 的修改都会停在一张卡片上，卡片提供**批准**、**始终允许**和**拒绝**，一次只等待一项修改。**审阅**会校验每次修改，把差异记入对话，然后在同一轮内应用。**自动**直接应用修改，但破坏性调用仍会先询问。提议的编辑处于预览状态时，预览栏提供**接受**和**放弃**。各项限制列在[让智能体作曲](agents.md)中。

## 诊断 {#diagnostics}

按 **Mod+Shift+D**，或者在偏好设置的**帮助与关于**页面选择**导出诊断信息…**，然后选择 `opencompose-diagnostics-<stamp>.tar.gz` 的保存位置。应用写出压缩包后会在文件管理器中显示它。压缩包包含 `manifest.json`、`logs/recent.log`、`project/project.ocp`、`environment.json`、`plugins/scan-summary.json` 和 `errors/last-error.txt`。无法收集的部分会在清单中记为 `missing`，并附上原因。

### 重新绑定快捷键 {#remapping-shortcuts}

打开**偏好设置 > 快捷键**，搜索命令表，选中一条命令，然后按下新的组合键。命令面板（Mod+Shift+P）读取同一张表，所以新绑定会立即出现在命令面板和快捷键列表中。

注册表位于 `crates/oc-gui/frontend/src/stores/commands.ts`。每条命令包含 id、标签键、类别、默认绑定和处理函数。持有本地状态的组件在挂载期间注册自己的处理函数。

自定义绑定以 `{ version: 1, bindings: { "<commandId>": "<binding>" } }` 的形式保存在 `localStorage` 的 `opencompose.keymap` 下。绑定字符串由 `Mod`、`Shift`、`Alt` 和按键名组成，例如 `Mod+Shift+Z`。

如果你绑定的按键已被另一条命令使用，绑定会被拒绝，提示信息会写出那条命令，原来的绑定保持不变。**重置**撤销一条自定义绑定；**恢复默认**在你确认后清除所有自定义绑定。Escape、Tab、只按修饰键以及命令面板自己的 Mod+Shift+P 是保留按键，不能分配。

## 磁盘上的文件 {#files-on-disk}

工程是 `.ocp` 文本文件，保存后的工程与命令行读取的是同一份文档。应用使用的其他文件：

- 媒体缓存：选择了配置目录时为 `<config>/cache/media`，否则为平台缓存目录（macOS 上为 `~/Library/Caches/OpenCompose/media`）。其中保存解码后的音频、拉伸版本和人声分析结果，这些都可以重新计算。
- 编辑历史、恢复副本、AI 对话和各种缓存：见[磁盘存储](../storage-layout.md)。
- 实时 MIDI 偏好设置：`~/.opencompose/midi.json`。
- 音频设备、采样率、缓冲区、录音布局和监听：`~/.opencompose/audio.json`。参见[音频设备](../audio-devices.md)。
- 智能体端点和令牌：`~/.opencompose/agent.json`。
- AI 服务商设置：`~/.opencompose/ai-providers.yaml`。密钥保存在操作系统的凭据存储中，绝不会写入工程。

## 从桌面打开工程文件 {#opening-project-files-from-the-desktop}

OpenCompose 会向操作系统注册 `.ocp` 文件。在 Finder、资源管理器或桌面文件管理器中打开工程，会把文档窗口带到最前面。第二次启动会把它的工程交给正在运行的应用，不会另开一个独立的编辑会话。应用接受文件路径和本地 `file:` URL；网络 URL 不会打开工程。

如果打开中的工程有未保存的编辑，在请求的文件替换它之前，你需要选择**保存**、**不保存**或**取消**。保存失败或你取消保存时，当前工程和提示框都会保留。**取消**会放弃这次打开请求。再次打开当前文件只会把它的窗口带到前面，你的编辑会保留。在应用启动期间或另一个对话框打开时收到的请求，会等到文档可以安全响应时再处理。

关闭最后一个文档窗口会退出应用，退出前同样会询问如何处理未保存的工作。隐藏或最小化窗口会让工程和播放会话留在运行中的应用里；在 macOS 上，单击程序坞图标即可恢复窗口。**退出 OpenCompose** 使用应用级的未保存工作提示。

## 查看片段信息 {#inspecting-a-clip}

右键单击片段可以查看它的属性，不会改变选区，也不会移动播放位置。菜单显示位置和时长、轨道、实际生效的预设、插件、音色补丁或源采样文件，以及相关的偏移、循环和处理设置。源路径是可选中的文本：选中路径后使用复制，复制的是文本，片段剪贴板不受影响。相对的媒体路径按工程文件所在位置显示，未保存的工程按原样显示相对路径。菜单不会检查文件是否真的存在于磁盘上。

选择**检查片段**，可以在**检查器**中保持这个视图打开。音符片段会在来源信息旁显示钢琴卷帘。音频片段显示文件、裁剪、增益、淡入淡出、拉伸和音高，不显示音符编辑器。

## 首次启动与外观 {#first-launch-and-appearance}

在你做出选择之前，OpenCompose 跟随系统的浅色或深色外观，并根据系统的首选浏览器语言列表选择界面语言。应用不支持的语言会回退到英文。设置界面会显示这些选项，包括**跟随系统**、**浅色**、**深色**以及明确的语言选择。选择**跟随系统**会继续跟随之后的系统变化；明确选择的主题或语言会保持你的设置。同样的设置也在偏好设置中，**帮助与关于 > 入门指南**可以重新打开设置界面，不会替换当前工程。

选择**播放测试音**可以听到一段轻柔的内置乐句，**停止测试音**结束播放，**音频设置**用来选择输出设备。你不需要 API 密钥，也不需要安装插件。在工作区选择界面中，**创建入门示例**会询问新的文件名，并写入一个完整的内置示例；它不会覆盖已有文件。

## 帮助与支持 {#help-and-support}

**帮助与关于**页面包含随附的英文手册、构建/源码/平台信息、公共代码仓库的链接、可离线查看的许可证和 SoundFont 声明，以及诊断信息导出。诊断文件保存在本地，其中包含工程源码、路径、日志、插件信息和系统详情，分享之前请先检查一遍。
