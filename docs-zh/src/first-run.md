# 首次启动

全新安装后，OpenCompose 会在准备窗口时显示一个简短的启动画面。首次启动时主题跟随系统：`prefers-color-scheme` 决定默认使用浅色还是深色。此后只有你在偏好设置中做出的选择才会改变它。

随后打开设置引导。它会扫描这台电脑，可能推荐一些免费插件和音色，最后用两步分别介绍编辑器和 AI 设置。

## 1. 这台电脑上的插件和音色

第一页先更新插件清单，再搜索音色文件夹，两项工作各有一个进度条。插件进度条会显示正在读取的插件包，每个插件包的辅助进程结束时计数一次。上次扫描结果仍然有效的插件包一开始就算作完成，所以重复扫描几乎瞬间结束。如果应用启动时开始的清单扫描还在进行，这一页会跟随那次扫描，不会再启动第二次。

扫描结束后，页面显示三项计数：

- **插件**（Plugins），按格式分别统计。扫描无法读取的插件包会带着说明列出，不计入可用插件。
- **乐器**（Instruments）：SoundFont 文件（`.sf2`、`.sf3`，按文件头识别）、SFZ 文件和采样器素材文件。
- **采样**（Samples）：音色文件夹中的 WAV、AIFF、FLAC、OGG 和 MP3 文件。它们只计数，不列出。

插件和乐器各有一个可折叠、可滚动的列表，第三个列表显示搜索过的文件夹。这台电脑上不存在的常用位置不会列出，只用一行说明跳过了几个。来自其他软件的设置、来自环境变量或来自 OpenCompose 安装的音色包的文件夹会带有标注。

**添加插件文件夹…** 和 **添加音色文件夹…** 会添加一个文件夹并重新扫描。**重新扫描** 会把每个插件重新读一遍，包括之前被扫描隔离的插件。会搜索哪些文件夹，见 [插件](manual/plugins.md) 一章中插件搜索位置一节。

## 2. 推荐（仅在找到的内容很少时）

当扫描找到的可读插件少于 10 个、乐器少于 3 个或采样少于 100 个时，会出现这一页，并说明缺少什么。

推荐内容和安装步骤来自签名的插件索引。应用本身只带有推荐列表中的 id，应用和 `ocp` 都不内置目录：名称、构建版本、下载地址、大小、校验和与安装脚本都由索引提供。如果打开引导时还没有缓存经过验证的索引，引导会按 **素材库** 使用的同一条自动路径获取一次；之后有了缓存副本，推荐在离线时也能显示。如果无法下载索引，页面会说明原因，并提供 **重试**。

获取失败时，页面会用插件索引测试已保存的线路、直连和常用的本地代理端口。只有某条线路确实返回了索引，页面才会提供它；点击一次即可应用该线路并重新获取。本地代理在运行却连不到索引时，页面会如实报告，不会提供这条线路。

**免费插件** 为每种用途列出一项：合成器、采样器、混响、饱和和混音。条目来自 **素材库** 使用的插件索引。每种用途优先选择已经安装的条目，其次是无需厂商安装程序就能安装的条目，再次是任何可安装的条目。已在前面用途中出现过的条目会被跳过。**安装** 与 **素材库** 走同一条经过验证的 `plugin_store_install` 路径。**取消** 会停止安装，**跳过引导** 则让安装继续进行。

**入门音色** 列出索引推荐的免费 SoundFont、SFZ 音色库和采样包。乐器少时显示乐器包，采样少时显示采样包。每张卡片显示发布者、内容类型、下载大小和解压后大小，以及许可证。点击许可证名称可以打开许可证全文，小字部分注明许可证要求的署名。**安装** 从发布者处下载压缩包，按签名目录核对大小和 SHA-256，然后解压到 OpenCompose 的音色文件夹，下次扫描就能找到。安装过程中，卡片显示下载、校验和解压进度，并提供 **取消**。音色存放在其他位置时，仍可使用 **添加音色文件夹…**。

## 3. 底部面板

`C`、`R` 和 `P` 分别在底部面板中打开 **片段**、**钢琴卷帘** 和 **预设** 视图。面板跟随当前选择，按键只是在面板内切换视图，不会打开新窗口。这一步还会指向工具栏中的 **AI 助手**，以及空格键：按空格会试听状态栏上显示的内容。

## 4. 模型

**打开 AI 设置** 会打开偏好设置的 **AI** 页面。那里的服务商、模型和凭据控件就是 AI 助手使用的那些。这一步可以跳过：编辑器、GM 乐器和效果器都不需要 AI 服务商。

## 关闭引导

点击 **跳过引导** 或完成最后一步，都会在 localStorage 中写入一个标记。只要这个标记还在，引导就不会再出现。如需重新打开，请选择 **偏好设置 > 帮助与关于 > 入门指南**。启动画面使用同一个首次启动标记，所以之后正常启动会直接进入工作区。
