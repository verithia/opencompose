# 装饰音

装饰音标记把一个写出的音符变成演奏者实际会弹出的若干音符，或者改变它的发声时长。标记保留在乐谱中：`ocp fmt` 会原样写回，之后也可以删除或替换。播放和 MIDI 导出会把它展开成普通音符，因此每条渲染路径听到的结果都一样。

```ocp
@project "Ornaments"
  tempo: 120
  key: C major

@track lead | instrument: synth/lead_saw
  @phrase line [1:1 - 3:1]
    C4 q mf ornament=trill
    E4 q mf ornament=mordent
    G4 h mf ornament=fermata
```

## 写法

| 标记 | 效果 |
|---|---|
| `ornament=trill` | 颤音：写出的音高与上方相邻音阶音交替。 |
| `ornament=mordent` | 波音：先奏写出的音高，再奏上方一级，然后保持写出的音高。 |
| `ornament=fermata` | 延长记号：发声时长变为写出时长的 1.5 倍。 |
| `ornament=arpeggio` | 琶音：与被标记音符同时开始的所有音符，按音高从低到高依次奏出。 |

一个音符最多带一个装饰音。其他取值都会被拒绝，错误信息会列出这四种写法，所以拼错的标记不会被当成普通音符播放。

## 上方音

颤音和波音的上方音取自音符所在位置的工程调性。在 C 大调中，`B4` 的上方音是 `C5`，`E4` 的上方音是 `F4`。调外音取它上方最近的音阶音。没有工程调性时，上方音是高一个半音，所以标记总有上方音，没有调性的工程也照样能播放。

上方音是音阶中的一级，因此更改工程调性会改变装饰音。它由调号决定，音符自身的临时记号不影响它。

## 时值

颤音先数出发声时长中包含几个完整的十六分音符，再把时长等分成这么多份。第一份奏写出的音高，第二份奏上方音，依此交替。份数为偶数时会结束在上方音上，所以颤音少用一份，以写出的音高收尾。因此一个四分音符会奏出三份，每份三分之一拍。短于三个十六分音符的音符没有交替的余地，保持原样。

波音先用一个十六分音符奏写出的音高，再用一个十六分音符奏上方音，然后在剩余时长里保持写出的音高。音符短于三个十六分音符时，这三部分平分时长，保证最后的写出音高不会丢失。短于两个十六分音符的音符保持原样。

两种标记都保留写出的力度记号和力度。带颤音或波音的音符不能同时带演奏法、弯音、颤音效果（vibrato）、表情曲线或滑音，因为它们都会为同一个音符描述第二条音高或电平路径。请去掉另一个标记，或者不加装饰音。颤音和波音需要单独的音符；用逗号列表写成的和弦请改用 `arpeggio`。

延长记号在演奏法和乐器修正之后再缩放发声时长，所以带延长记号的断奏音符仍然比持续音短。写出的时值、后续音符和小节计算都不变。

## 琶音

琶音把同一起点上的各个音符按音高从低到高，依次各延后一个三十二分音符。标记其中任意一个音符就会让整个起点的音符都琶音化，所以写成一个逗号列表的和弦只需标记一次：

```ocp
@track keys | instrument: piano/acoustic_grand
  @phrase chord [1:1 - 2:1]
    @0 C4 q mf ornament=arpeggio, E4 q mf ornament=arpeggio, G4 q mf ornament=arpeggio
```

和弦仍然占据它写在的那一拍。延迟是工程时间中的一个三十二分音符，因此会跟随速度映射。任何音符都不会被移到所在片段或乐句的开头之前。琶音保留每个音符的写出时值和全部演奏法。

## 播放与导出

这些标记只是简写，不增加 DSL 原语，也不增加引擎状态。解释器在发出音符事件之前展开它们，所以离线渲染、流式播放、乐段预览、区间渲染和 MIDI 导出收到的音符完全相同。不使用标记的工程完全按写出的内容播放。

展开结果受写出的发声时长约束。长颤音每个十六分音符最多产生一份，太短而放不进网格的音符保持原样，所以不会出现长度为零的部分。
