Choose a reference for the specific reggaeton feel. Dembow patterns vary by
production, so map the kick and snare from the intended reference before
adding the surrounding kit. Start with one bar and hear it repeated.

## Build the core pattern

- Use a named drum pattern and the actual kit's pad names. Put the steady
  kick on quarter beats for a straight perreo starting point. Try the snare
  on beat 1 subdivision 3 and beat 2 subdivision 2, then repeat that two-beat
  relationship on beats 3 and 4. Subdivisions count from 0.
- Hear kick and snare alone, then add a quiet straight eighth-note tick.
  Try a timbale, bell or stick response in a gap rather than on every hit.
  Keep the main snare recognizable when swapping percussion sounds.
- If a layered clap creates two attacks, start with shared placement.
  Check the sample heads and offset only if the layer still has a useful
  effect. Shorten the layer's decay or reduce its level when it obscures
  the main snare.

## Adapt the groove to the song

Set the bass note length while the kick is present. Shorten or release it
before a busy kick entrance if they blur. Check the low end with any long
snare or percussion tail included.
Change one surface part on a phrase ending while the core anchors continue.
Place vocal chops and fills in a lead-vocal gap or reduce their emphasis
where they share a stressed syllable.

Audition two repeats through the fill and the next downbeat. Check that the
variation adds direction without moving the perceived backbeat.
