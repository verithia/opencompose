title: Build dub techno echo returns
when: Dub techno chord stabs need filtered echoes and evolving space around a clear kick.
category: production

tools: [buses_add, buses_routes, tracks_send_add, buses_mix, devices_catalog, effects_add, effects_set_param, edit_subtree, render_range, audition_range]

Start with the dry kick and a short chord stab. Leave space after the stab
so you can hear what the return adds. Route one send into a delay bus and
send that bus to master. Keep the dry route and make the delay fully wet.

Set the repeat against a musical subdivision. If the delay uses time in
milliseconds, derive it from the tempo. A quarter note is 60000 divided by
BPM. Check the groove if the tempo changes. Use a modest feedback setting
and inspect the device controls before raising it.

Filter the repeat path or return to keep the sub clear. Filtering after
the delay shapes the audible repeats, while a filter in the feedback path
changes what accumulates inside the delay. Use the available control and
identify which of those jobs it does.

Vary which stab feeds the echo. Let the return ring out rather than
cutting it with every dry mute. Introduce texture quietly and leave room
for the first stab. Avoid feedback cycles between project buses.

Listen to repeated stabs, a section boundary, and the final tail. Check
for kick masking, low-band buildup and a repeat that grows over time.
