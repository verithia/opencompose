Decide what stays stable while the texture moves. Hold a quiet pitch
or field layer as a reference and reserve a second layer for motion.
Listen for enough space between entrances to hear each tail decay.

## Build an evolving source
Try two layers with different jobs: one supplies the core tone and the
other adds a slow, less predictable surface. On a pad, compare a shorter
attack with a longer one at the same note onset. The longer version
should still arrive in time to support the next sound.

For a file-backed granular oscillator, verify the loaded sample and
supported controls before adjusting grain length, density or scan.
Keep one parameter steady when changing another. Start with a smooth
window and increase overlap if the edges click. Use an ordinary audio
clip with slow gain movement when the patch or sample path is unavailable.

## Hear the seam and the room
Loop through a texture seam repeatedly. Compare a short equal-power
crossfade with a slightly longer one. Listen for both a dip and a swell
and try a quieter crossing point if neither version works.
Shape a dedicated space return so the low mids do not build up as the
tail extends. Compare a matched stereo and mono pass for a stable center.
