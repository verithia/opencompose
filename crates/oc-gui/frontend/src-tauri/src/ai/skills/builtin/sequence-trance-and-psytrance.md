Make the kick and rolling bass lock before adding the lead. Start with
separate tracks so note lengths, envelopes and levels can be checked alone
and in combination. Keep the same percussion loop across comparisons.

## Separate the subdivisions
Write repeated bass notes with clear starts. Adjust their length and
amp release until each attack is distinct and the kick body has space.
If kick and bass sound strong in isolation but weak together, inspect
overlap, the bass starting phase if the patch exposes it, and combined
low-end level. Try timing or release before raising the bass fader.

For a psytrance lead, sketch the notes first and audition a held pitch
while setting one supported modulation or warp control. Then try the same
timbre on the short repeated notes. Query devices_catalog for the actual
controls. Keep lead movement separate from the repeating bass pulse.
For melodic trance, repeat a short cell with a changed ending at the next
phrase boundary. Check harmony and note placement before adding a riser.

## Give the return room
At the transition, test one filter or layer-density change. If a delay
covers the returning lead, lower the send before the entry or shorten
the tail. Audition from before the buildup through the returned downbeat,
with the kick and bass present. Compare stereo with mono when available.
