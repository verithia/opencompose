Name the destination event and what the transition should prepare: a vocal
entrance, a drop, a fill ending or a quieter section. Choose a related source
so the transition belongs to the song rather than filling every gap with FX.

## Print a useful gesture
Keep the source. Isolate a short vowel, drum tail or texture and print a
bounded pass with enough release. Inspect which inserts and returns are
included. For a reverb swell, capture the intended wet tail, not an unnoticed
dry double. Confirm the available reverse and clip controls before editing.
Read resample-a-playable-instrument for print routing and retained paths.

## Place the arrival, then the start
A reversed file's beginning need not be the useful sync point. Identify
the swell peak or intended last transient and place that at the destination.
Use audio_clip_set_placement for fine timing; changing source offset chooses
a different portion of media. Re-list clips after cuts before using indices.
If stretch is needed, set it first and check arrival again after processing.
Use sparse automation or fades to shape energy, leaving the next attack clear.

Try a short dry answer, a reversed tail and intentional silence as alternatives.
Keep only the gesture that clarifies the section change. A riser does not need
an unrelated broadband sweep, long reverb and impact stacked by default.
Pitch only when it supports the harmonic arrival; noisy transitions need not
be assigned an arbitrary root. Keep low tails away from the new kick/bass.

## Verify across the boundary
Audition from the preceding phrase through the first full phrase afterward.
Check for a doubled vocal, late peak, lost downbeat and an unexpectedly clipped
tail. Then hear the source alone to identify any artifact processing introduced.
Level-match alternatives and listen for anticipation without excessive loudness.
Validate and retain the selected source/print so the transition reopens intact.
