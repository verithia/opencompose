Choose a reference for the specific scene and track. Mark its main pulse,
pickup, turnaround and the parts that stay silent.

## Transcribe the accent cycle
Audition two successive passes. Mark the events you hear as low anchor,
answer and supporting hit. Mark uncertain events separately. Use one pad
or track per role. Put the recurring anchor down first, then position the
answers against it. Preserve offsets that you can hear in both passes.
Use the same samples to make a version snapped to the nearest straight grid.
Compare the two to identify which timing changes matter. Swap one pad at a
time if the exercise is meant to use different samples from the reference.

## Compare sparse patterns

For a sparse gqom-inspired loop, choose one low impact as the anchor and a
second as an answer. Give one the weight and the other a shorter decay or
higher emphasis. Leave subdivisions empty when they help the answer land.

For a kuduro-inspired loop, write a clear hook and make the percussion
answer it with a different rhythm. Start with the main accents and add
shorter strokes between them. Leave space where the MC or lead enters.
Shorten one-shot tails with controlled fades if they crowd the next hit.

Loop the phrase, then mute layers one by one. If the movement disappears
when one layer is muted, decide whether that layer is the anchor or
whether it is doing work another part should do. Keep contrasting attacks
instead of flattening them into one common envelope.

Compare the bare groove with the busy section and the transition out.
Try changing one return for tension before filling every empty subdivision.
