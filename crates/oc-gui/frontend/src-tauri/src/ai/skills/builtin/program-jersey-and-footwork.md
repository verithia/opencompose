Write a two-bar count with a stable snare or clap before adding chopped
samples. Pick Jersey club or footwork phrasing based on the musical brief.
Both can use sharp edits, but the kick and sample should serve a clear pulse.

## Build one call and one answer
For Jersey club, place a short staggered or triplet kick figure near a
turnaround. Use positioned notes for precise timing when a drum-hit
subdivision cannot express the spacing. Check that the last pickup leads
to a strong first kick in the next bar. Shorten overlapping bass tails if
the cluster sounds like one sustained low note.

For footwork, start from the slower perceived snare anchor. Let a vocal
chop cross a bar line if the kick response still makes the phrase length
clear. Put the drum reply in a gap in the sample. Try alternating one
pitched vowel with a dry spoken fragment rather than doubling every cut.

## Keep edits intentional
Set the clip range and offset around the actual syllable, and move the
next chop if a retained gap feels accidental. Use the smallest fade that
removes a discontinuity. Leave a longer source fragment when the hook
needs a recognizable word. If a stop-start edit uses silence, audition
the first kick after the break to check its attack.
