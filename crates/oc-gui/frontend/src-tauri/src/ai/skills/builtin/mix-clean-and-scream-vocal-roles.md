Start from supplied authorized takes and hear them with the arrangement.
List lead melody, pitched grit, unpitched scream, unison support and harmony roles.
Name the focal voice in each section before deciding track count or processing.
A loud scream is not proof of a pitched note, and grit is not automatically damage.

## Select and align by role
Read comp-vocal-takes and retain alternatives rather than deleting unused takes.
Match intelligible attacks where words should strike together; preserve deliberate
looseness and do not stretch every noisy event to a detected transient.
Use audio_clips_list before edits and re-list after a split changes indices.
Retain breath ownership and compare whole words through every edit seam.
For a pitched line, compare the stable vowel against actual harmony before tuning.
Native local clip pitch/formant edits are not a note-curve or detection-blob editor.
Do not force unpitched consonants or scream texture through scale correction.
Request a supported external edit or a better source when segmentation is wrong.

## Keep clean and texture processing distinct
Use exclusive clean and aggressive subgroups when their level/tone jobs differ.
A shared compressor couples voices; it cannot independently fix each layer.
Choose peak control, body leveling or saturation by the heard fault, not a chain
copied from a source with different level and capture. Inspect actual device units.
Compare one stage first, then add a second only for a remaining distinct problem.
Check sibilance and room noise after every density or brightness addition.
Use a separate wet role for scale/depth; more hall is not inherently more epic.
Tune return timing against the next lyric, leaving the dry articulation dependable.

## Add only useful density
Prefer an actual alternate take for independent unison motion. A delayed copy
adds a different effect and may comb in mono; identify it honestly.
Give a harmony a chord-aware line, and place choir or scream support selectively
where it supplies weight or an answer rather than covering every lead syllable.
No fixed number of takes, forced register or physical scream technique is required.

Render the same clean-to-aggressive transition before and after, with master fixed.
Use a matched local audio_compare pair, then audition_range through the complete
section. Compare lyrics, attack, low-mid buildup and tiring upper-mid density.
Remove each added layer once; keep it only if its named role is lost when absent.
Restore solo states and retain the dry takes plus chosen prints for later revision.
