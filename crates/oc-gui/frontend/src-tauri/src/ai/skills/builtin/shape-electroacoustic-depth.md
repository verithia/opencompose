---
id: shape-electroacoustic-depth
title: Shape electroacoustic depth and motion
when: A sound object or field recording needs a deliberate near-to-far gesture in a stereo electroacoustic piece.
category: arrangement
version: 1
tools: [tracks_list, project_extract, edit_subtree, buses_add, tracks_send_add, devices_catalog, render_range, audition_range, audio_analyze]
---
Pick one sound object and define its position, apparent distance and
motion at the beginning and end. Make the gesture audible in a dry pass.
Pan gives a lateral cue. Level, brightness and direct-to-reverberant balance
give different distance cues.

Shape dry level and brightness on the object. Add space from a separate
return so its tail can continue after the dry event ends. Automate one
dimension first, then add others only where they reinforce the trajectory.
Use editable anchors around important events and check the motion in context.

Keep quiet objects identifiable between denser events. Use distinct timing,
bandwidth or stereo positions before making every object louder. Resample
a complex gesture to a new clip only if the printed version serves the edit.
Keep the unprinted source if later movement must remain editable.

Check the stereo version on a stereo path and audition a mono fold-down for
missing objects. Confirm where a quiet event starts and where its tail ends.
Correlation is supporting evidence and cannot describe a trajectory.

If the work requires multichannel delivery, verify the actual host and export
path separately. Report the channels that were rendered and heard.
