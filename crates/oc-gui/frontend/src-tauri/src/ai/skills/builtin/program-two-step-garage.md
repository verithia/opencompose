Start with a clearly audible backbeat and write the kick pattern around it.
Skip selected quarter-note kicks to create the two-step feel. Establish
a two-bar anchor before introducing fills or extra layers.

## Give different parts different timing
Keep main snare accents stable while trying softer pickups before them.
Use a separate pattern for hats or ghost hits if only those offbeat eighths
should swing. The swing setting moves offbeat eighths, so write the desired
position directly for later subdivisions. Compare on the same two bars and
keep only changes that add forward motion without a new flam.

Play a short bass note against the quiet spaces in the kick pattern.
Leave the bass tail out of the next kick attack. Place one or two vocal
chops as answers to the bass, then leave a gap so the pattern can breathe.
For a future-garage bed, keep the texture quiet and use a filtered return
if the vocal or ambience leaves a low tail over the bass.

## Verify the feel
In positioned audio clips, check each chop's range, source offset and fade.
Use clip pitch when the duration should stay put and the formant change
is acceptable. Recheck pitch and timing after any stretch.
Audition drums alone, then drums with bass and the full loop. If the
pattern loses its backbeat at low volume, simplify the pickups first.
