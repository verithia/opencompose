## Write the chord skeleton
Start with one eight-bar build-to-drop window. Check the vocal's key, pickup
and phrase ending against the grid before writing the drop around it.
Sketch the progression with a plain piano and separate bass roots. For a
four-bar test, try these voicings above a single C2, A1, E2, and G1 respectively:

| Harmony | Upper voices, low to high |
|---|---|
| Cmaj7 | G3 E4 B4 |
| Am9 | G3 C4 E4 B4 |
| Em7 | G3 D4 E4 B4 |
| Gadd9 | A3 D4 G4 B4 |

Use the shared upper note as an anchor and listen to the inner changes.
Move or remove an extension if it clashes with a sustained vocal syllable.
Transfer the approved voicing to the chord synth. Keep the bass roots on
their own track and shorten the sub where a new kick needs space.

## Arrange two versions of the transition
Keep a quieter version of the same harmonic bed in the build. Try opening
one layer with automation while another makes space for the last vocal line.
Leave a short breath before the drop if it helps the first accent land.
Give the first drop phrase separate roles for drums, chords, sub and lead.
Put a vocal chop or lead answer in a gap rather than following every chord hit.
On the second phrase, change the chord rhythm or the answer before adding a
new layer. For patch design, read design-and-verify-supersaw and design-future-bass-wobble.

## Check what changed
Validate the edits and audition the build and drop together at similar playback
level across versions. If the drop feels smaller, test more silence before it
or less density in the build. If the sub disappears, isolate kick plus sub,
then bring back chords to find which layer obscures it.
Check the first hit, the chord changes and the lead's answer in the full mix.
