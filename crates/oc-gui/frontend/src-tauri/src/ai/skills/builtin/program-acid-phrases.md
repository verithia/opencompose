Treat pitch order, rhythm, accents and slides as separate decisions.
Read translate-a-production-technique and inspect the actual voice/filter controls.
Start with one supported rich waveform, a low-pass filter and restrained drive.
Leave room below the output ceiling before raising resonance or accent gain.

## Write the phrase before the sweep
Choose a short motif and a clear return point against a fixed drum groove.
Mark which steps sound, which rest, and which continue the preceding note.
A tie sustains a note; a rest creates space. Neither automatically means a slide.
Use a few deliberate accent locations instead of random velocity on every step.
Keep pitch and note timing fixed while comparing an unaccented version.
For accents, compare level and filter opening as separate destinations.
Do not assume velocity drives timbre until its route has been established.

## Calibrate slides and envelopes
Inspect voice.mono, voice.legato and voice.glide in devices_catalog.
Test a detached interval, an overlapping interval and return to a held note.
Confirm whether the selected glide follows every note or only overlaps.
Hear the envelope restart separately from the pitch movement.
A single global filter envelope cannot be assumed to mimic a dedicated accent circuit.
Use supported note articulation or explicit automation for the intended gesture.
Keep the bass arrival stable even when the approach slides.
Compare a short and long interval to hear whether glide duration changes.

## Perform and verify
Open cutoff in a phrase-sized arc, then tune resonance and envelope depth together.
Use release and note gaps to keep the kick and next bass onset clear.
Change only one rhythmic or tonal state at a section boundary.
Compare dry, driven and full-mix versions at matched level.
Test start, loop wrap, mid-phrase seek and the note after a rest.
Listen for stale held notes, lost accent contrast, clipped peaks and smeared slides.
Save the editable phrase and patch; retain a print only for a chosen variation.
State any approximation instead of claiming an exact circuit reproduction.
