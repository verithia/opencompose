## Choose by the observed problem
For source choice use select-samples-by-role; for weak sound use diagnose-a-sound.
For unfamiliar controls use translate-a-production-technique and actual support status.
For phrases use develop-melodic-phrases; for harmony use voice-chords-around-bass-and-melody.
For tonal center use establish-a-modal-center; for section roles use balance-a-mix-by-role.
For sampled timing use fit-loops-with-pitch-and-time; for tails use verify-sample-trigger-and-source-state.
For pads use assemble-a-sampled-drum-kit; for selected prints use resample-a-playable-instrument.
For motion use calibrate-modulation-and-trigger-state; for width use check-stereo-balance-and-mono.
For dynamics use hear-compression-and-recovery or compare-multiband-and-parallel-dynamics.
For quiet detail use calibrate-gates-and-quiet-detail; for space use choose-and-shape-reverb.
For repeat tails use design-delay-feedback-and-ducking; for word timing use shape-vocal-phonemes-and-prosody.
For vocal layers use stack-vocal-harmonies; for speech over music use mix-dialogue-and-a-music-bed.
For media ownership use prepare-project-media and prepare-a-portable-production-template.
Finish with review-a-complete-arrangement, then master-for-delivery for the actual destination.

An exercise proposes a comparison, not a verified result or mandatory chain.
Use the user's reference and authorized media when available. Check that the
required sources, controls and external host exist before starting the exercise.
Record missing dependencies and what audio was actually heard. A short excerpt
cannot establish complete-song delivery or detail outside its delivered bandwidth.
