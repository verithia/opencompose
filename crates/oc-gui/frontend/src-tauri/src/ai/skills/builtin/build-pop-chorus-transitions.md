Read the actual section ranges and find the hook pickup. Listen across the
boundary before deciding where the chorus starts to feel larger.
Name one change that should read at the entry: stronger rhythm, a new upper
register, a fuller bass return or a change of harmony.

## Build contrast before adding loudness

- Carry one motif or chord idea out of the pre-chorus so the section feels
  connected. Thin part of its register, shorten a pattern or remove one
  strong accent immediately before the entry. Let the chorus restore it.
- Try an upper-octave layer only on the phrase you want to emphasize. Bring
  it in under the main part. Leave the lead and bass centred where they
  already work, and audition any width change in mono.
- Leave a gap for the lead pickup. Use a shorter fill or move its onset
  earlier when a long snare, riser or reverb tail blurs the first consonant.
  If you have a prepared reverse swell, place its end against the audible
  word and listen for the edit rather than assuming a bar line is the target.

## Check the handover

If an existing filter creates the build, inspect its automation and recovery.
The target should reach the open value by the intended bass attack. Check
whether smoothing makes a written downbeat point arrive perceptually late.
Keep the effect curve and the arrangement changes separable for comparison.

Audition the last pre-chorus bars through the first complete chorus phrase.
Compare at similar loudness. Check the pickup, bass return and first chorus
line. Try a smaller change if the peak rises while the hook stays buried.
